Se descargará un único ZIP con solo las secciones modificadas. No hace Commit ni Push, no modifica el repositorio y no elimina tus borradores.

Cómo publicar

  1. Antes de editar, utiliza Fetch/Pull origin en GitHub Desktop, para partir de la versión más reciente del equipo.
  2. Abre esta pantalla desde el mismo navegador y dirección de Live Server en que guardaste los borradores. Revisa los contadores de cambios pendientes y pulsa Preparar todo y descargar ZIP.
  3. Extrae el ZIP en la raíz del repositorio desde GitHub Desktop → Repository → Show in Explorer. Fusiona sus carpetas data, articulos, ejercicios, examenes y las demás que aparezcan, conservando archivos ajenos al ZIP.
  4. Revisa ARCHIVOS-A-RETIRAR.txt, si aparece. Si eliminaste un artículo o PDF, borra también del repositorio los archivos allí indicados; quitar una entrada del índice no elimina el archivo físico.
  5. Comprueba los cambios con Live Server: calendario, artículos, figuras, ejercicios, exámenes y demás contenido exportado.
  6. En GitHub Desktop, revisa los cambios, haz Commit y después Push origin. Comparte con los compañeros la versión publicada.

Importante: GitHub Desktop solo detectará los cambios después de extraer el ZIP en la carpeta correcta. Si no hay borradores pendientes, el botón permanecerá desactivado y no generará un paquete vacío. Un aporte creado en otro navegador u origen no aparece automáticamente aquí. No se limpian borradores al exportar; no incluyas documentos sin autorización.
