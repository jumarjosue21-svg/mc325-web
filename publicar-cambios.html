Cómo publicar

  1. Antes de editar, utiliza Fetch/Pull origin en GitHub Desktop, para partir de la versión más reciente del equipo.
  2. Descarga el ZIP y extrae su contenido en la raíz de tu copia local del repositorio, combinando las carpetas data, articulos y pdfs. Reemplaza los JSON del proyecto cuando se solicite; conserva los archivos existentes que no aparezcan en este ZIP.
  3. Revisa ARCHIVOS-A-RETIRAR.txt, si aparece. Si eliminaste un artículo o PDF, borra también del repositorio los archivos allí indicados; quitar una entrada del índice no elimina el archivo físico.
  4. Comprueba el calendario y los artículos con Live Server; revisa las figuras de los artículos si sus imágenes están disponibles.
  5. En GitHub Desktop, revisa los cambios, haz Commit y después Push origin. Comparte con los compañeros la versión publicada.

Importante: los cambios hechos en este navegador no son públicos hasta que los archivos generados estén efectivamente en el repositorio y GitHub Pages haya desplegado la versión actualizada. No incluyas respaldos privados ni PDFs sin autorización.
