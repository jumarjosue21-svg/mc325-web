Pasos para publicar

  1. Antes de sobrescribir archivos, haz Fetch/Pull origin en GitHub Desktop y comprueba que no haya cambios de tus compañeros pendientes de integrar.
  2. Descarga el ZIP desde esta página.
  3. Abre la carpeta raíz del repositorio mc325-web y extrae el ZIP allí, fusionando carpetas. Debe reemplazarse únicamente data/contacto.json.
  4. Abre contacto.html con Live Server en una ventana de incógnito y comprueba los datos y los controles de visibilidad.
  5. Realiza Commit y Push origin en GitHub Desktop. Cuando GitHub Pages se actualice, verifica la página pública.

Por privacidad, el ZIP no incluirá correos ni celulares cuya visibilidad esté desactivada. No publiques datos personales sin la autorización de sus titulares. Esta herramienta de prueba no autentica administradores.
