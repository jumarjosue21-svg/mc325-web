Pasos para publicar

  1. Antes de reemplazar el JSON, revisa en GitHub Desktop los cambios de tus compañeros. Haz Fetch/Pull con el repositorio limpio.
  2. Genera el ZIP y extrae su contenido en la raíz de mc325-web. Debe sustituirse únicamente data/recursos.json.
  3. Comprueba mediante Live Server, preferiblemente en incógnito, que los recursos y su orden sean correctos.
  4. Revisa Changes, realiza Commit y Push origin. Verifica GitHub Pages cuando se despliegue.

Si un compañero también modificó data/recursos.json, no lo sobrescribas: compara los registros y fusiona los cambios. El exportador detecta discrepancias entre el borrador y el JSON que sirve tu Live Server, pero no puede detectar automáticamente todos los cambios de GitHub remoto. El Modo Docente todavía no tiene autenticación.
