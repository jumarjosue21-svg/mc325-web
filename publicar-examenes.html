Preparar exámenes para GitHub

Genera un ZIP que incluye el catálogo actualizado, los PDF y los artículos Markdown nuevos o modificados. No sube archivos automáticamente a GitHub. Es el mismo proceso de publicación manual utilizado en otras secciones del proyecto.

Abre esta herramienta desde el mismo navegador y origen web (por ejemplo, Live Server) donde guardaste los cambios. Revisa antes de exportar si tus compañeros han actualizado el repositorio.

Volver a exámenes

Antes de limpiar: descomprime el ZIP en la raíz del repositorio, revisa los archivos, haz Commit y Push desde GitHub Desktop, y verifica que la web publicada funcione. Nunca reemplaces un JSON desactualizado sin conciliar primero los cambios de otros colaboradores.
