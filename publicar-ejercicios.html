Preparar ejercicios para GitHub

Esta herramienta prepara un ZIP con los cambios de Ejercicios Resueltos. No sube nada directamente a GitHub. Debes incorporar el contenido al repositorio y hacer Commit y Push desde GitHub Desktop.

Ábrela desde el mismo Live Server y navegador donde agregaste o editaste los ejercicios. Los PDF se leen desde el almacenamiento local del navegador.
