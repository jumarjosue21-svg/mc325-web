## Enunciado

Una barra de acero laminado en caliente presenta una resistencia mínima a la fluencia en tensión y compresión de $S_y = 350\text{ MPa}$. Mediante la teoría de la **energía de distorsión (DE)** y la del **esfuerzo cortante máximo (ECM)**, determine los factores de seguridad correspondientes a los siguientes estados de esfuerzo plano:

| Caso | $\sigma_x$ (MPa) | $\sigma_y$ (MPa) | $\tau_{xy}$ (MPa) |
|:---:|:---:|:---:|:---:|
| 1 | $100$ | $100$ | $0$ |
| 2 | $100$ | $50$ | $0$ |
| 3 | $100$ | $0$ | $-75$ |
| 4 | $-50$ | $-75$ | $-50$ |
| 5 | $100$ | $20$ | $-20$ |

---

## Estrategia de resolución

> **Procedimiento general para cada caso:**
> 1. Calcular los esfuerzos principales en el plano $\sigma_1$ y $\sigma_2$ (mediante círculo de Mohr o expresiones analíticas).
> 2. Incorporar $\sigma_3 = 0$ (condición de esfuerzo plano) y ordenar los esfuerzos principales de mayor a menor: $\sigma_1 \ge \sigma_2 \ge \sigma_3$.
> 3. Evaluar ambos criterios de falla estática y obtener sus respectivos factores de seguridad.

* **Esfuerzos principales en el plano:**
  $$\sigma_{1,2} = \frac{\sigma_x + \sigma_y}{2} \pm \sqrt{\left(\frac{\sigma_x - \sigma_y}{2}\right)^2 + \tau_{xy}^2}$$

* **Esfuerzo equivalente de von Mises (DE):**
  $$\sigma_{\text{VM}} = \sqrt{\sigma_1^2 - \sigma_1\sigma_2 + \sigma_2^2}, \qquad n_{\text{DE}} = \frac{S_y}{\sigma_{\text{VM}}}$$

* **Esfuerzo cortante máximo (ECM / Tresca):**
  $$\tau_{\max} = \frac{\sigma_{\max} - \sigma_{\min}}{2}, \qquad n_{\text{ECM}} = \frac{S_y}{\sigma_{\max} - \sigma_{\min}}$$

> *Nota sobre Tresca:* Dado que $\sigma_3 = 0$ forma parte del conjunto de esfuerzos principales, si $\sigma_1$ y $\sigma_2$ tienen el mismo signo, la diferencia máxima se toma respecto a cero ($\sigma_{\max} - 0$), y no entre $\sigma_1$ y $\sigma_2$.

---

## Solución paso a paso

### Caso 1 · σx = σy = 100 MPa (estado hidrostático plano)

Al ser $\tau_{xy} = 0$ y $\sigma_x = \sigma_y$, los esfuerzos principales son $\sigma_1 = \sigma_2 = 100\text{ MPa}$ y $\sigma_3 = 0$.

$$\sigma_{\text{VM}} = \sqrt{100^2 - (100)(100) + 100^2} = 100.0\text{ MPa} \implies n_{\text{DE}} = \frac{S_y}{\sigma_{\text{VM}}} = \frac{350}{100} = 3.50$$

$$\sigma_{\max} - \sigma_{\min} = 100 - 0 = 100\text{ MPa} \implies n_{\text{ECM}} = \frac{S_y}{\sigma_{\max} - \sigma_{\min}} = \frac{350}{100} = 3.50$$

En este estado biaxial igual ambos criterios coinciden, ya que corresponde a uno de los puntos de contacto entre la elipse de von Mises y el hexágono de Tresca.

### Caso 2 · σx = 100 MPa, σy = 50 MPa, τxy = 0

Los esfuerzos principales son $\sigma_1 = 100\text{ MPa}$, $\sigma_2 = 50\text{ MPa}$ y $\sigma_3 = 0$.

$$\sigma_{\text{VM}} = \sqrt{100^2 - (100)(50) + 50^2} = \sqrt{7500} = 86.60\text{ MPa} \implies n_{\text{DE}} = \frac{S_y}{\sigma_{\text{VM}}} = \frac{350}{86.60} = 4.04$$

$$\sigma_{\max} - \sigma_{\min} = 100 - 0 = 100\text{ MPa} \implies n_{\text{ECM}} = \frac{S_y}{\sigma_{\max} - \sigma_{\min}} = \frac{350}{100} = 3.50$$

El criterio DE arroja un factor de seguridad mayor (menos conservador), mientras que ECM resulta igual o más conservador.

### Caso 3 · σx = 100 MPa, σy = 0, τxy = -75 MPa

$$C = \frac{\sigma_x + \sigma_y}{2} = \frac{100 + 0}{2} = 50\text{ MPa}, \qquad R = \sqrt{\left(\frac{\sigma_x - \sigma_y}{2}\right)^2 + \tau_{xy}^2} = \sqrt{50^2 + (-75)^2} = 90.14\text{ MPa}$$

$$\sigma_1 = C + R = 50 + 90.14 = 140.14\text{ MPa}, \qquad \sigma_2 = C - R = 50 - 90.14 = -40.14\text{ MPa}, \qquad \sigma_3 = 0$$

$$\sigma_{\text{VM}} = \sqrt{140.14^2 - (140.14)(-40.14) + (-40.14)^2} = 163.94\text{ MPa} \implies n_{\text{DE}} = \frac{S_y}{\sigma_{\text{VM}}} = \frac{350}{163.94} = 2.14$$

$$\sigma_{\max} - \sigma_{\min} = 140.14 - (-40.14) = 180.28\text{ MPa} \implies n_{\text{ECM}} = \frac{S_y}{\sigma_{\max} - \sigma_{\min}} = \frac{350}{180.28} = 1.94$$

Al tener esfuerzos principales de signos opuestos, $\sigma_3 = 0$ queda entre ambos y la diferencia crítica corresponde a $\sigma_1 - \sigma_2$.

### Caso 4 · σx = -50 MPa, σy = -75 MPa, τxy = -50 MPa

$$C = \frac{\sigma_x + \sigma_y}{2} = \frac{-50 - 75}{2} = -62.5\text{ MPa}, \qquad R = \sqrt{\left(\frac{\sigma_x - \sigma_y}{2}\right)^2 + \tau_{xy}^2} = \sqrt{(-12.5)^2 + (-50)^2} = 51.54\text{ MPa}$$

$$\sigma_1 = C + R = -62.5 + 51.54 = -10.96\text{ MPa}, \qquad \sigma_2 = C - R = -62.5 - 51.54 = -114.04\text{ MPa}$$

Al incluir $\sigma_3 = 0$, el orden de mayor a menor es $\sigma_{\max} = 0\text{ MPa}$ y $\sigma_{\min} = -114.04\text{ MPa}$:

$$\sigma_{\text{VM}} = \sqrt{(-10.96)^2 - (-10.96)(-114.04) + (-114.04)^2} = 108.97\text{ MPa} \implies n_{\text{DE}} = \frac{S_y}{\sigma_{\text{VM}}} = \frac{350}{108.97} = 3.21$$

$$\sigma_{\max} - \sigma_{\min} = 0 - (-114.04) = 114.04\text{ MPa} \implies n_{\text{ECM}} = \frac{S_y}{\sigma_{\max} - \sigma_{\min}} = \frac{350}{114.04} = 3.07$$

### Caso 5 · σx = 100 MPa, σy = 20 MPa, τxy = -20 MPa

$$C = \frac{\sigma_x + \sigma_y}{2} = \frac{100 + 20}{2} = 60\text{ MPa}, \qquad R = \sqrt{\left(\frac{\sigma_x - \sigma_y}{2}\right)^2 + \tau_{xy}^2} = \sqrt{40^2 + (-20)^2} = 44.72\text{ MPa}$$

$$\sigma_1 = C + R = 60 + 44.72 = 104.72\text{ MPa}, \qquad \sigma_2 = C - R = 60 - 44.72 = 15.28\text{ MPa}, \qquad \sigma_3 = 0$$

$$\sigma_{\text{VM}} = \sqrt{104.72^2 - (104.72)(15.28) + 15.28^2} = 97.98\text{ MPa} \implies n_{\text{DE}} = \frac{S_y}{\sigma_{\text{VM}}} = \frac{350}{97.98} = 3.57$$

$$\sigma_{\max} - \sigma_{\min} = 104.72 - 0 = 104.72\text{ MPa} \implies n_{\text{ECM}} = \frac{S_y}{\sigma_{\max} - \sigma_{\min}} = \frac{350}{104.72} = 3.34$$

> **Conclusión:** El **Caso 3** es el más crítico de los evaluados, con $n_{\text{DE}} = 2.14$ y $n_{\text{ECM}} = 1.94$. En todos los casos se cumple $n_{\text{ECM}} \le n_{\text{DE}}$, lo que confirma que el criterio de Tresca es igual o más conservador que el de von Mises.

## Preguntas de repaso

* **¿Por qué en el Caso 1 coinciden DE y ECM, pero en el Caso 3 no?** En el Caso 1 se presenta un estado biaxial igual ($\sigma_1 = \sigma_2$), donde la elipse de von Mises y el hexágono de Tresca se intersectan. En el Caso 3 hay signos opuestos y un esfuerzo cortante relevante, zona donde ambas fronteras se separan más y DE entrega un factor de seguridad superior.
* **Si el Caso 3 presenta $n_{\text{ECM}} = 1.94$, ¿ocurre fluencia en el elemento?** No, ya que $n > 1$ indica que no se alcanza la fluencia; sin embargo, si el requisito de diseño exige por ejemplo $n_d = 2.0$, el estado no cumpliría dicho margen.
* **¿Cuál es la consideración práctica para $\sigma_3$ en estado plano de esfuerzos?** Su valor es $\sigma_3 = 0$ y debe incluirse al ordenar los esfuerzos principales antes de aplicar el criterio de Tresca.
